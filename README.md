# Hospital EMR Data Analytics Project

## 1. Project Title

Hospital EMR Analysis 

## 2. Project Overview

This project uses Microsoft Power BI to analyze hospital data and understand patient activity, treatment costs, revenue, patient types, financial classification, and hospital service times. The analysis demonstrates how hospital data can be cleaned, transformed, modeled, and visualized to support data-driven decision-making.

## 3. Problem Statement

Hospitals generate large amounts of patient, treatment, financial, and operational data. Without proper analysis, it can be difficult to identify patterns in patient activity, revenue, treatment costs, financial classes, and service times.

This project addresses this challenge by transforming hospital data into meaningful indicators and interactive visualizations that can help monitor hospital operations and financial performance.

## 4. Data Source

The project used a hospital dataset obtained from *Kaggle*, a platform for publicly available datasets and data science resources.

The dataset contains information related to:

- Patient demographics and clinical information
- Treatment costs and length of stay
- Consultation revenue and laboratory costs
- Patient type and financial class
- Entry, consultation, and completion times

## 5. Methodology

The project followed these main steps:

1. Imported the hospital datasets into Microsoft Power BI.
2. Cleaned and prepared the data using Power Query.
3. Transformed data types and prepared the dataset for analysis.  
4. Developed DAX calculations for analysis.
5. Analyzed patient, financial, treatment, and service-time information.
6. Created interactive Power BI dashboards and visualizations.
7. Interpreted the results and identified useful indicators.

### Tools Used

*Microsoft Power BI | Power Query | DAX*

## 6. Key Insights

The analysis produced the following key findings:

- The dataset contained approximately *30K patients*.
- *Private* financial class generated the highest total revenue, followed by *Insurance, while **Medicare* generated the lowest revenue.
- *Insurance* recorded the highest patient count, followed by *Private* and *Corporate, while **Medicare* recorded the lowest patient count.
- All recorded patients were classified as *Outpatients*.
- The average waiting time was approximately *38.92, while the average visit time was approximately **43.83*.
- Revenue fluctuated during the analyzed period, with noticeable peaks around *November 5 and November 11* and the lowest revenue around *November 13*.

## 7. Conclusion / Recommendations

### Conclusion

The analysis demonstrates how Power BI can be used to transform hospital EMR data into meaningful information about patient activity, financial class performance, revenue patterns, and service times. The dashboard provides hospital management with a clear view of patient volumes, revenue performance, and operational indicators.

### Recommendations

Based on the findings, the hospital should:

- *Review the factors contributing to the high revenue from Private patients* and use the findings to improve overall financial performance.
- *Monitor the low patient volume and revenue associated with Medicare* to understand whether accessibility, registration, or other factors are affecting utilization.
- *Monitor waiting and visit times* and identify opportunities to improve patient flow and service efficiency.
- *Analyze the revenue peaks and low-revenue periods* to understand the factors causing fluctuations and improve planning.
- *Use the dashboard regularly* to monitor patient volume, financial class performance, revenue, and service-time indicators for data-driven decision-making.
