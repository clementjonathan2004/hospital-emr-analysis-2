# Hospital Data Analytics Project

## Project Overview

A hospital data analytics project developed using Microsoft Power BI to analyze patient volume, treatment costs, revenue, patient type, financial classification, and hospital service times.

## Objectives

- Clean and prepare hospital datasets
- Analyze patient and financial information
- Measure waiting, consultation, and visit times
- Create DAX calculations for analysis
- Develop interactive Power BI dashboards

## Data

The project used publicly available hospital datasets containing information such as:

- Patient demographics and clinical information
- Treatment costs and length of stay
- Consultation revenue and laboratory costs
- Patient type and financial class
- Entry, consultation, and completion times

## Analysis

The analysis focused on:

- Patient volume and patient type
- Treatment costs and revenue
- Financial class performance
- Waiting time and visit duration
- Patient outcomes and readmission
- Revenue trends

## Key Insights

The project demonstrates how hospital data can be transformed into useful indicators for monitoring patient activity, financial performance, and operational efficiency.
